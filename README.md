# 🔐 Show/Hide Password

A beginner-friendly mini project to toggle the visibility of a password field using HTML, CSS, and JavaScript.

## 💡 Features
- Toggle between "password" and "text" input types
- Eye icon changes based on visibility
- Simple, clean UI

## 📦 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript



## 🚀 How to Use
1. Clone this repository
2. Open `index.html` in your browser
3. Enter a password and click the eye icon to toggle visibility
